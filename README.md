轻量化离线桌面访客登记工具
访客簿 APP 是一款基于 Python 原生技术开发的极简离线桌面访客登记工具。项目极致精简功能，摒弃冗余复杂的信息录入与管理模块，仅聚焦核心需求，支持访客姓名新增登记、访客名单查看、姓名检索功能。本程序无网络依赖、无服务端部署、极低资源占用，专为个人日常简易访客记录场景设计，适配轻量化使用需求，同时开放完整源代码，可供学习与个性化二次调整。
一、项目定位
本项目为个人超轻量化日常简易工具，区别于常规多功能访客管理系统，以「极简、轻便、易用」为核心设计原则。仅服务于个人办公、家庭工作室、小型门店等仅需简单登记来访人员姓名、留存访客名单的轻量化场景，无需录入复杂访客信息，无多余操作流程，零部署成本、零网络依赖，兼顾普通用户极速上手与开发者简易二次开发需求。
二、核心优势
- 全离线运行机制：程序全程离线运行，无联网请求、无数据云端上传逻辑，所有访客数据仅本地存储，从根源保障数据私密性。
- 超轻量化极低消耗：原生极简代码开发，无第三方冗余依赖、无多余功能模块，程序体积小巧，CPU、内存资源占用极低，兼容全系Windows、Mac桌面设备。
- 零学习使用门槛：可视化极简图形界面，操作逻辑单一清晰，仅支持新增、查看、检索操作，无复杂配置与流程，所有用户可即时上手。
- 数据持久化存储：系统自动留存所有登记的访客姓名数据，程序关闭、设备重启后数据不丢失，稳定留存访客登记台账。
- 精准姓名检索机制：内置专属姓名模糊检索功能，可通过关键词快速匹配、筛选已登记访客姓名，高效完成名单查阅。
- 极简开源可调整架构：源码结构清晰、逻辑精简、注释规范，无冗余耦合代码，支持开发者简易功能微调与界面优化。
三、系统功能模块
3.1 访客姓名简易登记
系统采用极简登记模式，仅支持新增录入访客姓名，无电话、事由、单位等额外信息录入模块。用户输入访客姓名后即可一键提交保存，快速完成简易访客登记，替代传统临时纸质记录，满足日常极简登记需求。
3.2 访客名单全量查看
系统以规整列表形式展示所有已登记的访客姓名台账，页面排版简洁清晰。用户可直观浏览全部历史访客登记名单，完整留存日常来访记录，满足基础台账查看、信息核对需求。
3.3 访客姓名模糊检索
系统专属支持访客姓名关键词模糊查询，用户输入任意姓名关键词，即可快速筛选匹配对应的访客登记记录，无需手动逐条翻阅名单，高效完成目标访客信息查找。
3.4 本地独立数据管理
所有访客姓名数据统一归档存储于程序本地目录，数据完全由用户自主掌控。程序无需依托任何网络与云端服务，离线状态下可正常使用全部功能，保障本地登记数据安全可控。
四、项目文件结构
本仓库为项目完整源码仓库，整体架构极简、文件分层清晰、逻辑高度精简，无冗余代码与无效资源，便于日常轻量化使用与简易二次调整，具体文件结构说明如下：
- 访客簿.py：项目核心启动入口文件，承载访客姓名登记、数据本地存储、检索核心业务逻辑。
- 访客簿GUI.py：图形界面逻辑文件，负责极简窗口布局、新增登记、名单展示、检索交互等页面渲染与事件响应。
- appuserbook.ico：程序专属图标资源文件，用于桌面客户端窗口标识。
五、运行环境说明
5.1 源码运行环境
- 操作系统：Windows 全系列系统
- 运行依赖：Python 3.8 及以上版本
- 依赖组件：采用 Python 原生内置库，无需额外安装第三方依赖包
源码启动方式：配置对应版本 Python 环境后，在项目根目录执行启动指令即可运行程序，部署流程极简，无复杂配置操作。
5.2 成品程序运行环境
项目提供编译完成的桌面可执行程序，普通用户无需配置 Python 开发环境，解压程序包后即可直接运行，实现开箱即用的极简访客登记体验。
六、系统功能约束说明
为维持程序极致轻量化特性，本系统功能做精简约束，仅保留核心基础能力：仅支持新增访客姓名、查看全部访客名单、检索访客姓名，不支持新增、编辑、查看访客电话、来访事由、单位、时间等其他拓展信息，无多余编辑、删除、导出功能，全程保持极简运行架构。
七、适用场景
本工具专为极简访客记录场景设计，适用于个人办公、家庭工作室、小型沿街门店、私人临时办公场景等无需详细访客信息登记，仅需简单留存来访人员姓名的日常轻量化使用场景。
